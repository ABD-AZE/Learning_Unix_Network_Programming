5a Analysis

    0 14 
    14 0

    Explanation:
    This program demonstrates byte order (endianness) conversion using htons().

    1. Initial value: port = 5120 (decimal) = 0x1400 (hexadecimal)

    2. First printf output: "0 14"
    - Prints each byte of 'port' in memory order
    - Intel processors use little-endian byte order
    - 0x1400 is stored as: [0x00, 0x14] in memory
    - Output shows: 0 14 (low byte first, then high byte)

    3. After htons(port): port2 = htons(5120)
    - htons() converts from host byte order to network byte order
    - Network byte order is big-endian
    - Converts 0x1400 to big-endian format

    4. Second printf output: "14 0"
    - Shows port2 bytes in memory order
    - After htons(), the bytes are swapped: [0x14, 0x00]
    - Output shows: 14 0 (high byte first, then low byte)

    Key Concept: Intel x86/x64 processors use little-endian, but network protocols use big-endian (network byte order).
